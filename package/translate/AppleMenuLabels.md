# Apple menu label references

Checked against Apple's localized Mac User Guide on 2026-10-11.
The menu, sleep, power, and lock-screen guides below provide the wording.
When an overview uses a descriptive heading instead of an action name, the
action instructions take precedence.

Kpple Menu retains “About This Computer” and its translations because it runs
on KDE Plasma. Logout remains generic until the current user's name is added.
“App Store” is Apple's brand name in every referenced locale, so it remains
“App Store” here too.

The guides commonly omit menu punctuation. Kpple Menu uses ellipses for
System Settings, App Store, Restart, Shut Down, and Log Out, following Apple's
[menu-label convention](https://developer.apple.com/design/human-interface-guidelines/menus).
About, Sleep, and Lock Screen have no ellipsis. German uses a space before
its ellipsis; Traditional Chinese uses the centered ellipsis shown in Apple's
power-action instructions. Settings field labels use the same wording with
colons instead of menu ellipses.
